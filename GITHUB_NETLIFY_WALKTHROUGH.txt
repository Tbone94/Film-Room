COMMANDERS PULSE — GitHub + Netlify Walkthrough

1. Upload / commit this folder to your GitHub repo.
2. In Netlify, connect the GitHub repo or drag/drop this ZIP.
3. Build command: npm run build
4. Publish directory: .
5. After deploy, go to GitHub → Actions → Build Commanders Pulse → Run workflow.
6. The workflow commits data/reddit-pulse.json and data/reddit-pulse-history.json.
7. Netlify should redeploy after the commit if the repo is connected.
8. Refresh the site to see Fan Pulse, hot topics, player buzz, and community headlines.

No Reddit login/password is needed.
