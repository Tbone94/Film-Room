GRIDIRON INTEL — FUNCTION DIAGNOSTIC DEPLOY

Why this version exists:
- Reddit browser requests are commonly blocked by CORS/network policy.
- The app needs a server-side function at /.netlify/functions/reddit-search.
- Drag/drop static deploys often publish index.html but do not reliably deploy serverless functions.

Required files/folders:
- index.html
- sw.js
- manifest.webmanifest
- icon.svg
- netlify.toml
- netlify/functions/health.js
- netlify/functions/reddit-search.js
- package.json

Best deployment method:
1. Unzip this folder.
2. Put the folder in a GitHub repository.
3. In Netlify, choose Add new site > Import an existing project.
4. Connect the GitHub repository.
5. Build command: npm run build
6. Publish directory: .
7. Deploy.

After deployment, test this first:
https://YOUR-SITE.netlify.app/.netlify/functions/health

Expected:
{"ok":true,"service":"gridiron-intel-netlify-functions",...}

Then test Reddit proxy:
https://YOUR-SITE.netlify.app/.netlify/functions/reddit-search?subreddit=fantasyfootball&q=Ja%27Marr%20Chase&limit=3

Expected:
- A JSON array = proxy is working.
- A JSON error object = function deployed, Reddit blocked upstream request.
- HTML page / 404 / site homepage = function did not deploy.
- Browser says Failed to fetch = function/network request did not reach the function.

Important after redeploying:
- Hard refresh the site.
- Clear site data if the old service worker keeps the old version.
- Remove/reinstall the PWA if it was installed to your phone home screen.
