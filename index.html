Setup checklist

This build is ready for GitHub + Netlify. Push the ZIP contents to the repo, then run the workflow once from GitHub Actions.

1. Deploy app

Netlify can publish this static app from the repo or from the ZIP. The ZIP has index.html at the root.

2. Run scraper

GitHub → Actions → Build Commanders Pulse → Run workflow. It writes data/reddit-pulse.json.

3. Verify pulse

Reload the site after the workflow commits. The pulse, topics, player buzz, and headlines should populate automatically.
